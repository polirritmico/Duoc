Para comunicar PC cada uno tiene su IP única.

Cada dirección IP tiene una submáscara. Define si equipos comparten o no una
red; se pueden o no comunicar entre ellos.

255 es dirección de broadcast

Puerta de enlace -> es la dirección IP que ocupa el router para conectar con el
exterior.

Tenemos una IP pública y otra privada. La privada es la dirección del computador
dentro de la LAN. La pública, la ip del router. Es la dirección que muestran los
servicios de identificación pública. Es la ruta que nos conecta a internet.

> Los ISP tienen un rango de diracciones ip asignadas.
