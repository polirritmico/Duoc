# Arquitectura

## Matriz de taconomía de patrones

### Estructurales (organización)

**N-capas:** separación vertical. Ejemplo Presentación -> dominio -> datos.

**Cliente-servidor:** Separación de responsabilidades e petición y respuesta.
Filtro de tubería (Pipe-Filter): procesamiento secuencial de datos.

### Distribuidos

**Master-Slave:** Un nodo delega a múltiples trabajadores.

**Persona a Persona (p2p):** Nodos actúan como cliente y servidor
simultáneamente.

**Agente (Broker):** Intermediario que enruta mensajes entre clientes y
servidores.

### Comportamiento

**Bus de eventos:** Nodos actúan como cliente y servidor simultáneamente.

**Modelo vista controlador (MVC):** Separación de interfaz, lógica y control.

**Pizarra (Blackboard):** Múltiples fuentes de conocimiento actualizan una
solución central.

## Tipos de Arquitectura a Gran escala

Combina la interfaz de usuario, la capa de negocios y la base de datos en un
solo sistema.
