# Clase Triggers

```sql
create or replace trigger trg_audit_atencion
  after insert on atencion    -- cuando y sobre que
  for each row                -- nivel: una vez por fila
begin
  insert into autditoria_atencion (ate_id, operacion, usuario, fecha)
  values (:new.ate_id, 'insert', user, sysdate);
end;
```

Opciones disponibles

- before: se puede modificar `:new` , los datos entrantes.

```sql
if inserting then ... elsif updateing then ... else ... end if;

values(nvl(:new.ate_id, :old.ate_id), v_op; user, sysdate);
```

- after: se puede usar `:old`

> [!NOTE]
>
> El trigger puede fallar y la query ejecutarse correctamente.

> [!TIP]
>
> Ojo con la trazabilidad de los triggers porque se puede producir un blucle
