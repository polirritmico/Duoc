# Clase 09: Procedimientos almacenados

(Experiencia 2.1)

```sql
CREATE OR REPLACE PROCEDURE sp_saludo (p_nombre VARCHAR2) IS
BEGIN
  BDMS_OUTPUT.PUT_LINE('Hola, ' || p_nombre);
END;
/ -- con este '/' se ejecuta una acción a la vez.

EXECUTE sp_saludo('Clinica KETEKURA');

```

> [!TIP]
>
> Siempre conviene tener el commit a nivel de backend y no en el procedimiento,
> para que se valide en el momento final.
