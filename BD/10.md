# Gestión de BD

**DBA** Control del uso y funcionamiento de la base de datos.

## Creación de usuario

Nos debemos conectar con el usuario `SYSTEM`.

Cada usuario tiene un esquema asociado.

```sql
CREATE USER usuario
IDENTIFIED BY constraseña
[DEFAULT TABLESPACE nombre_tablespace]

CREATE SESSION -- --> Permisos de conexión.
GRANT SELECT ON esquema.tabla TO usuario;
GRANT CREATE VIEW TO user

```

### Crear vista

CREATE OR REPLACE VIEW v_foo
