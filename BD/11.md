# PL/SQL

- bloque anonimo
- funcion almacenada: fun
- procedimiento almaceno:
- trigger
- package: header + body.

Bloque anónimo variables a utilizar dentro de nuestro bloque anónimo (asignación
con `:=`) toma el tipo de dato de esta tabla, de esta columna

```sql

DECLARE
	v_nombre_completo varchar2(255) := 'Alan Brito';
	v_renta	cliente.renta_cli%TYPE;
BEGIN
	SELECT
		nombre_cli || ' ' || appaterno_cli || ' ' || apmaterno_cli AS nombre
		,renta_cli
	INTO
		v_nombre_completo
		,v_renta
	FROM cliente
	WHERE numrut_cli = 12251882
    ;
	DBMS_OUTPUT.put_line('NOMBRE: ' || v_nombre_completo);
	DBMS_OUTPUT.put_line('RENTA: ' || TO_CHAR(v_renta,'$999g999g999'));
EXCEPTION WHEN OTHERS
		DBMS_OUTPUT.put_line('ERROR- ');
END;
```
