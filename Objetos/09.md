# Colecciones. Clase 2025-10-09

Todas reciben solo un tipo de dato. Son una familia.

## Listas

Las colecciones del tipo lista tienen las siguientes características:

- Son Ordenadas
- Son dinámicas en tamaño

Tienen los siguientes métodos:

- add
- remove
- size
- contains
- isEmpty
- Streams (java 8):
  - forEach
  - map
  - flatMap
  - filter

### Tipos:

1. ArrayList: Tratan de estar continuos en memoria. No necesariamente mantienen
   el órden.
2. LinkedList: Preserva el órden, pero _tiende_ a ser más lenta.

## Conjuntos

- No permiten elementos repetidos

## Mapas

- Similares a los diccionarios tienen llave y valor

Métodos:

- put(k, v)
- get(k) => v
