# Herencia y Polimorfismo. Clase 2025-10-21

Relación entre clases. Hay una _clase padre_ o superclase que hereda atributos y
comportamientos hacia una subclase o clase hija.

`protected` sirve para compartir miembros de una superclase a una subclase.

```java
class Animal {
  pivate String nombre;

  public void setNombre(String nombre) {
    this.nombre = nombre;
  }
}

class Gato extends Animal {
  gatito.setNombre("Michi");
}
```

Para acceder a un miembro de la superclase desde la subclase se utiliza `super`,
similar a como `this` accede a los miembros de la misma clase.

## Constructor

Cuando una clase padre tiene un constructor no estándar, por ejemplo,
`public Foo(String arg) {...}` la clase hija en su constructor debe pasar las
instrucciones para el constructor padre:

```java
class Bar extends Foo {
  public Bar() {
    super("buz");
  }
}
```

Se utiliza `instanceof` para trabajar con clases especificas heradadas de una
misma clase padre:

```java
for (Animal animal : animals) {
  System.out.println("Nombre: " + animal.getName());

  if (animal instanceof Cat cat) {
    cat.getSomethingOnlyTheCatCouldDo();
  }
}
```
