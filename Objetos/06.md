## Clases

Una clase es la plantilla para construir un objeto.

Aquí escribimos atributos y métodos.

```java
public class NombreClase {
  // Atributos
  TipoData nombreVariable;
  OtroTipo otroNombre = "un valor";

  // Métodos
  public TipoRetorno nombreMetodo() {
  }
}
```

Reglas nombres

- Nombre de las clases -> Sustantivos
- Nombre los métodos -> Verbos
