# Gráficos

## Gráfico circular o de torta

> [!TIP]
>
> Se utiliza para frecuencia relativa y variable cualitativa.

El gráfico de torta va a ser para variables cualitativas, mientras el gráfico de
barras es para una **variable cuantitiva discreta** en términos generales.

En el gráfico circular se van a expresar las frecuencias relativas.

En general las frec abs y relativas van a ser más útiles.

## Gráfico de barras

> [!TIP]
>
> Se utiliza para frecuencia abs para una variable cuantitativa discreta.

Debe aparecer la variable independiente (eje x) y la dependiente (eje y).

## Histograma

> [!TIP]
>
> Se utiliza para variable cuantitativa continua, para frecuencia absoluta

La unica diferencia con el de barras es que las ramas van juntas. Se recomienda
para frecuencia absoluta, para variables cuantitava continua.

Es uno de los más utilizados en estadísticas. Para ver probabilidades del clima.
