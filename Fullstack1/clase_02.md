# Clase 02

## Consistencia de datos en un contexto de microservicios

Por ejemplo, si un microservicio necesita un código de servicio y en algún lugar
del proceso ese código se trunca, entonces hablamos que ese dato tiene baja
consistencia.

Hay herramientas que documentan las API de forma casi automática agregando
pequeños elementos al código.

## Frontend

Se refiere a la parte visible de una aplicación. Maneja:

- HTML
- CSS
- Javascript
- Frameworks y librerías

## Backend

Se refiere a la lógica del servidor, la BD y otras infraestructura que soportan
la aplicación.

- Lenguajes de programación
- BD
- API y servicios web
- Seguridad y autenticación

> Fullstack = Backend + Frontend

## Frameworks

Nos permite desarrollar rápido y evitar escribir funcionalidades comunes por
nuestra cuenta desde 0.

Desventajas:

- Por lo general requieren de una curva de aprendizaje para utilizarlo
  correctamente.
- Plantea una metodología de trabajo rígida, lo que puede generar conflictos con
  algunos proyectos.
- Quizás pueden incluir funcionalidades que nunca utilicemos.

¿Cuándo hablamos de framework y librería?

El framework trae herramientas bibliotecas y mejoras prácticas.
