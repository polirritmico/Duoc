# Clase 11

## Proyecto

- Debe tratar de una problemática real.
- Es un sistema completo. Es decir, solucionar **todo** lo que involucra.
- Mínimo 10 microservicios independientes. Cada uno con una responsabilidad
  clara y con sus propios endpoints.
- Cada microservicio debería tener su propia DB normalizada y diagrama de
  modelos de datos.
- El sistema debe contemplar entre 2 o 3 roles de usuario diferenciados.
