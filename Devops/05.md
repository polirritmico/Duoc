## Orquestar con docker compose

Docker compose es una herramienta que permite gestionar aplicacions compuestas
por múltiples contenedores de manera sencilla usando un archivo YAML.

Configuración declarativa en `docker-compose.yaml`.

sintaxis:

- context -> donde esta el Dockerfile
- container_name -> Nombre del container
- ports -> host:container
- resources -> para limitar usos
