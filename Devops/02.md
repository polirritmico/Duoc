## GIT

Git es un sistema de control de versiones distribuido, que rastrea cambios en el
código, permitiendo colaboración eficiente y reversión de errores. Nos permite
mantener versiones del código o ramas.

### Comandos vistos

```bash
git add
git commit
git push
git checkout
git fetch
git pull
```
