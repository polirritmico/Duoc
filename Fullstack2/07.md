# Clase 07: Prop, State, Hook

## Prop

Sirve para pasar funciones entre componentes.

```javascript
export default function FooComponent({ barProp })
```

## State

Estado de los componentes. Al cambiar el estado se obliga a refrescar el
componente.

## Hook

Funciones de React que a vienen escritas. Por ejemplo, para trabajar con el
`LocalStorage`, se usa un Hook para utilizarlo. Los Hook se declaran con `use`.
