# Clase 03

Estructura de una págia. No confundir el `header` con el `head`. El primero
habla del contenido y el segundo de la metadata del html.

```txt
html
├─head
│ ├─configuración
│ ├─css
│ └─metadata
└─body
  ├─header
  │ └─nav
  ├─main
  │ └─div
  └─footer
```
