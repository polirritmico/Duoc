# Clase 5. Javascript

Javascript utiliza un tipado dinámico.

Se manejan 3 tipos de variables. El tipo de variable es de tipo antiguo `val`,
`const` que no se modifica y `let` para variables que se mofican. Evitar
utilizar `val`.

```javascript
val foo
```
