## HTML

HyperText Markup Language es el lenguaje de marcado estándar utilizado para
crear y estructurar contenido en la web. Es el componente fundamental de la web,
proporcionando la estructura básica de las páginas web.

```html
<html>
  <head></head>
  <body></body>
</html>
```

**Páginas responsivas:** Que se adecúa al tamaño de pantalla del dispositivo.
Por ejemplo, la página que se adapta tanto a un celular como PC de escritorio.
