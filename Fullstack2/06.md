Es una biblioteca de JavaScript de código abierto desarrollada por Facebook/Meta
utilizada para construir interfaces de usuario, específicamente para
aplicaciones de una sola página (SPA) donde los datos cambian dinámicamente a lo
largo del tiempo sin recargas la página completa.

Permite la creación de componentes reutilizables que pueden manejar su propio
estado interno.

## Principales características

Un componente es una pieza independiente y reutilizable de código que describe
una parte de la interfaz de usuario. Pueden ser clases js o funciones que pueden
manejar su propio estado y ciclo de vida.

## JSX

React usa Javascript XML. una extensión de la sintaxis de JS que permite
escribir código que se parece a HTML dentro de js. JSX facilita la creación de
componentes y la definición de la estructura de la interfaz de usuario de una
manera declarativa.

```jsx
const element = <h1>Hello world</h1>;
```

---

Los componentes vienen a ser los distintos elementos de una página HTML, por
ejemplo, los headers, footer, y partes del contenido.
