## Elementos de una página

- `navbar:` Barra de navegación
- `container:` Contenedor principal de la página
- `grid:` Grillas, organizan el contenido en columnas
- `buttons`: Botones
- `forms:` Formularios
- `cards:` Contenido agrupado
- `alerts:` Mensajes al usuario
- `tables:` Mostrar datos tabulares
- `modal:` Ventanas emergentes
- `list:` Listados
- `badge:` Etiquetas/Estados
- `pagination:` Navegación entre páginas
- `dropdown:` Menús desplegables
- `accordion:` Contenido expandible
- `carousel:` Galería/slideshow de contenido
- `footer:` pie de página

## Estructura de la página

```text
html
├─head
│ ├─configuración
│ ├─css
│ └─título
└─body
  ├─header
  │ └─nav
  ├─main
  │ └─div
  └─footer
```

- `body:` contiene el cuerpo de la página
- `main:` identifica el contenido principal
- `container:` controla el ancho y organiza el contenido
- `.row:` crea una fila del grid
- `.col-*:` divide la fila en columnas

Bootstrap divide el contenido de un container en 12 secciones o columnas.

```html
<div class="container">
  <div class="row">
    <div class="col-6">columna izquierda</div>
    <div class="col-6">columna derecha</div>
  </div>
</div>
```

## Breakpoints

Para hacer el contenido responsivo y adaptarlo a cada pantalla se utilizan los
breakpoints.

```html
<div class="container">
  <div class="row">
    <div class="col-lg-6 col-md-12">columna izquierda</div>
    <div class="col-6 col-md-12">columna derecha</div>
  </div>
</div>
```

## Márgenes de elementos

> Elemento: Lo visible e invisible de la página, todo tag html.

Usar mt, mb, ms, me

## Ordenar y alinear elementos

Antes de elegir una clase conviene preguntarse:

- ¿Quiero alinear horizontalmente o verticalmente?
- ¿quiero mover un elemento o distruibuir varios?

## Estructura del proyecto:

```text
proyecto/
├── css/
├── img/
├── js/
└── pages/
```

- `HTML:` Estructura y contenido. ¿Qué hay?
- `CSS:` Estilos. ¿Cómo se ve?
- `JavaScript:` Comportamiento ¿Qué hace?

### Ejemplo: Creando un botón

```html
<button id="btnSaludar" class="btn btn-primary">Saludar</button>
```

JavaScript puede hacer que ocurra algo cuando se presiona:

```javascript
document.getElementById("btnSaludar").addEventListener("click", function () {
  alert("¡Hola!");
});
```
