# Clase 04

## Listas

```kotlin
val numerosMutables = mutableListOf(1, 2, 3)
numerosMutables.add(4)
println(numerosMutables) // salida [1, 2, 3, 4]
```

## While

```kotlin
val datos = listOf("A", "B", "C")
var i = 0
while (i < datos.size) {
  println("Procesando: ${datos[i]}")
  i++
}
```

## Do While

```kotlin
val datos = listOf("A", "B", "C")
var i = 1
do {
  println("Procesando: $item")

```

## For

```kotlin
val datos = listOf("A", "B", "C")
for (item in datos) {
  println("Procesando: $item")
}
```

## For Each

```kotlin
val datos = listOf("A", "B", "C")
datos.forEach { item ->
  println("Procesando: $item")
}
```

## filter

```kotlin
val numeros = listOf(1, 2, 3, 4, 5)
val pares = numeros.filter { it % 2 == 0 }
println(pares) // [2, 4]
```

## map

```kotlin
val numeros = listOf(1, 2, 3)
val multiplicados = numeros.map { it * 10 }
print(multiplicados) // [10, 20, 30]
```

## chaining

```kotlin
data class Usuario (val nombre: String, val edad: Int)
val usuarios: List<Usuario> = obtenerUsuarios()

val nombresAdultos: List<String> = usuarios
  .filter { it.edad >= 18 }  // 1. Filtra por edad
  .map { it.nombre }         // 2. Extrae el nombre
```
