# Clase 6. Corrutinas

- suspend fun: función que puede ser pausada y reanudada.
- coroutineScope: Drefine el ciclo de vida de una corrutina preivniendo fugas de
  memoria.
- launch: Constructor para iniciar una tarea
- async:

```kotlin
import kotlinx.coroutines.*

suspend fun fetchDataFromApi(): String {
  res: String = bigTask()
  return res
}
```

El puente síncrono: runBlocking vs GlobalScope

- GlobalScope.launch: Se ejecuta la corrutina en un hilo en segundo plano. No
  bloquea el hilo principal. Si el main termina, la corrutina muere
  instantáneamente.
- runBlocking: Crea una corrutina y bloquea el hilo actual hasta que todas las
  tareas en su interior finalicen por completo.

```kotlin
import kotlinx.coroutines.*

suspend fun fetchDataFromApi(): String {
  res: String = bigTask()
  return res
}

// runBlocking vendría siendo un scope de corrutina.
fun main() = runBlocking {
  println("Inicio de main")
  var data = fetchDataFromApi()
  println("Fin")
}
```

### let

En lugar de hacer esto:

```kotlin
if (civic != null) {
  civic.conducir(distancia = 50)
  println(civic.describir())
}
```

```kotlin
civic?.let {
  it.conducir(distancia = 50)
  println(it.describir())
}
```
