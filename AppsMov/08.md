## Window Size Classes

Básicamente responsive, pero en Android. Se clasifica la pantalla.

| Clasificación | Ancho mínimo | Descripción física                          |
| ------------- | ------------ | ------------------------------------------- |
| Compact       | < 600dp      | Celulares vertical                          |
| Medium        | 600dp-840dp  | Celulares grandes, tablets pequeñanses      |
| Expanded      | > 840dp      | tablets grandes, modo horizontal, foldables |

## Buenas prácticas

- Usa calculateWindowSizeClass() solo una vez por pantalla.
- Evita BoxWithConstraints si tu objetivo es adaptabilidad estructural.
- Diseña desde el princip para Comparct, luego expande.
- Combínalo con Navigation.
