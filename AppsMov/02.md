# Clase 02

## Actividad responder las siguientes preguntas:

### Sobre el Desarrollo Nativo:

1. ¿Cuál es la característica principal que define a una aplicación nativa?

   Interactúa directamente con el SO.

2. ¿Qué dos lenguajes son los más relevantes para el desarrollo nativo en
   Android?

   Kotlin y Javascript.
   https://kotlinlang.org/docs/multiplatform/programming-languages-cross-platform.html#popular-cross-platform-programming-languages-frameworks-and-technologies

3. ¿Qué lenguaje es el estándar actual para el desarrollo nativo en iOS?

   Swift.

4. Identifica y describe dos ventajas clave del enfoque nativo, especialmente en
   relación con el rendimiento y la experiencia de usuario.

   Al trabajar a más bajo nivel, permite interactuar con el hardware
   directamente, como por ejemplo sensores específicos, etc.

   Por otro lado, los binarios están más optimizados por lo que la experiencia
   tiende a ser más fluida.

5. ¿Cuál es la principal desventaja del desarrollo nativo en términos de tiempo
   y recursos?

   Que es específico para la plataforma y por ende no se puede reutilizar el
   código ni aplicar conocimiento técnico específico a otra plataforma.

### Sobre el Desarrollo Multiplataforma:

1. ¿Cuál es la promesa o el objetivo principal de los frameworks
   multiplataforma?

   Programar una vez y que funcione en las plataformas soportadas.

2. Nombra tres frameworks multiplataforma populares y el lenguaje de
   programación que utiliza cada uno.
   - Kotlin Multiplatform: Kotlin
   - Flutter: Dart
   - React Native: Javascript/Typescript

3. Identifica y describe dos ventajas clave de este enfoque, especialmente
   relacionadas con los costos y la velocidad de desarrollo.
   - Ahorro de tiempo
   - No requiere conocimiento específico
