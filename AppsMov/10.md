# Clase 10: Animaciones y local storage

En jetpack compose, si no guardamos las variables, cada vez que se refresque la
aplicación, por ejemplo al minimizarla o ir y volver de pantalla, el contenido
de esas variables se va a borrar. Por ejemplo, seteamos una variable a `Hola`,
cuando se minimice la aplicación, esa variable va a volver vacía.

Para retener el estado, creamos un modulo `EstadoDataStore.kt` donde básicamente
tenemos una `booleanPreferencesKey`.

Para leer la variable tenemos un `Flow`.
