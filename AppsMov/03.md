# Clase 03

## Lenguajes

### Kotlin

Lenguaje de programación desarrollado por JetBrains. Tiene menos boilerplate que
Java. Incorpora características como el manejo seguro de nulls.

### Java

Lenguaje estable con más de 3 décadas de uso en la industria. Desarrollado por
Sun Microsystems (dueños de Oracle). Enfoque al desarrollo orientado a objetos,
gran comunidad y soporte.

---

## Null safety

```kotlin
var a: String? = "Hello"
a = null // permitido

val lengthSafe = a?.length
val lengthForced = a!!.length // lanza null pointer exception
```
