# Clase 05. Clases, herencia y polimorfismo.

Kotlin es un lenguaje orientado para POO.

## Clase

```kotlin
class Foo(val foo: String, val bar: String, var buz: Int) {
  // hay 2 constructores el de arriba y el de abajo.
  // el de abajo l
  // los constructores permiten usar los : para llamar a otro constructor
  constructor(foo: String, var: String): this(foo, bar, 123) {
    println("New foo")
  }

  fun foo(bar: String): String {
    return "bar: $bar"
  }
}
```

> [!INFO]
>
> Para que Bar pueda heredar de Foo, Foo necesita tener `open`. Por ejemplo:
> `open class Foo...`

## Encapsulamiento

- **public (default):** Accesible desde cualquier lugar.
- **private:** Accesible solo dentro de la misma clase.
- **protected:** Accesisble desde la misma clase y subclases
- **internal:** Accesible solo dentro del mismo proyecto.

### Try-Catch

```kotlin
fun foo(bar: Int): Double {
  res: Double = 0.0
  try {
    res = 1/bar
  } catch (e: AritmeticException) {
    println("Error")
  } finally:
    return res
}
```

Se puede retornar un Result. Puede ser un Success o un Failure

Existe el tipo `Result` que agrega `foo.onSuccess` y `foo.onFailure`.
