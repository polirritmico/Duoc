# Android

Hay 2 bifurcaciones principales: Desarrollo nativo y Frameworks multiplataforma.

## La filosofía multiplataforma

En base a un código base se genera una aplicación tanto para Android, iOS, Web.

Las 3 plataformas más usadas son:

- **React Native:** Creado por Meta. Utiliza JavScript y React.
- **Flutter:** Desarrollo por Google. Utiliza el lenguaje Dart.
- **Ionic:** Framework de código abierto que utiliza tecnologías web estándar
  (HTML, CSS, JS/TS).
